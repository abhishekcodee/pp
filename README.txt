PRAYAS website: 6 linked pages
================================
Pages (keep all files in the same folder): index.html, about.html, students.html, employers.html, resources.html, contact.html
Open index.html in a browser. Every menu link works.

1. PHOTOS: put image files in the images/ folder. See images/PUT-PHOTOS-HERE.txt for the exact file names.
2. ENQUIRY FORM (contact.html): follow the steps at the top of google-apps-script.gs, then paste the web app URL where the
   page says PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE (search for it inside contact.html). Until then the form shows the phone number.
3. INSTAGRAM VIDEOS (resources.html): find  const IG=[]  and paste reel/post links inside the brackets, each in quotes,
   e.g. const IG=['https://www.instagram.com/reel/XXXXXXXX/'];
4. LINKS TO PAGES OUTSIDE THIS PACKAGE: student-portal/register.php, student-portal/login.php, privacy-policy.html and
   terms-and-conditions.html exist on the live site. They work only when these files sit on the same site.
5. TEXT: the page text matches the content draft. Text added from the current website will be synced here after the final review.
